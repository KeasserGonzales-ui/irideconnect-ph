# 🏍️ iRideConnect PH

> **Philippine Motorcycle Community Platform** — Connecting riding clubs, charity motorcades, medical missions, roadside assistance, and merchant sponsors across the Philippines.

Developed with ❤️ by **Keasser Gonzales**.

---

## 🌟 Key Features

- 📅 **Interactive Event Calendar**: Google Calendar-style layout with real-time category filters, co-host counts, and interactive hover popovers.
- 🤝 **Inter-Club Collaboration**: Join as co-hosting riding clubs and communicate via the live coordination board.
- 🔑 **Super Admin Oversight**: Full administrative control to manage and revise all events and sponsor campaigns.
- 🏍️ **Riding Clubs Directory**: Searchable directory of verified motorcycle clubs across Philippine provinces.
- 📞 **Verified Roadside Emergency Hotlines**: 24/7 direct dialers for Quezon Provincial Highway Patrol (HPG), Philippine Red Cross (143), and local towing services.
- 🛠️ **B.L.O.W.B.A.G.E.T.S. Safety Checklist**: 10-point pre-ride motorcycle safety inspection widget.
- 📢 **Official Merchant Marketplace**: Sponsor ad carousel, promo vouchers, and quote requests.

---

## 🚀 Live Demo & Deployment

This project is built with semantic HTML5, Vanilla CSS3 (Glassmorphism), and modern JavaScript. It can be hosted on GitHub Pages, Netlify, or Vercel with zero configuration.

### Running Locally:
```bash
# Using Python
python -m http.server 3000

# Or using Node.js http-server
npx http-server -p 3000
```
Open your browser at `http://localhost:3000`.
